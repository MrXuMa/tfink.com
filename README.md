# tfink.com

Personal cybersecurity portfolio and blog for **Tyler Fink** — FSU CS, Jr SOAR Engineer.

## Stack

- [Astro](https://astro.build) (static) + Netlify
- UnoCSS · Motion · Markdown content collections

## Content

| Path | Purpose |
|------|---------|
| `src/data/projects.ts` | Projects list (+ optional GitHub `repo` URLs) |
| `src/data/blog/*.md` | Blog posts |
| `public/blog/fsu-ctf/` | CTF write-up PDFs |
| `src/site-config.ts` | Name, links, site URL |

Based on [astro-bento-portfolio](https://github.com/Ladvace/astro-bento-portfolio) (MIT).
